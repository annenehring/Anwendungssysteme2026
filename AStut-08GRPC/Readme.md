In this project, we show how to create a simple grpc server and client that communicate with each other. If you change the `.proto` files, you might have to manually run the maven goal `protobuf:compile-custom` to update the Grpc-related autogenerated code 

If you have problems with this project, please try the following steps:

- run the maven goals `jar:jar`, `protobuf:compile`, and `protobuf:compile-custom`
- re-import the whole project and reload all maven projects
